# Origin Income v8.3 — Passwort-Reset

Neu in dieser Version:

- `/passwort-vergessen`: versendet automatisch eine Reset-Mail über Supabase.
- `/auth/callback`: tauscht den sicheren PKCE-Code gegen eine Session.
- `/passwort-zuruecksetzen`: prüft den Link und speichert das neue Passwort.
- Login-Link „Passwort vergessen?“ ist bereits mit dem Ablauf verbunden.

## Test nach dem Deployment

1. In Supabase unter Authentication → Users einen Testnutzer anlegen, falls noch keiner existiert.
2. Auf der Website Login öffnen → „Passwort vergessen?“.
3. E-Mail-Adresse des Testnutzers eingeben.
4. Link in der Supabase-Mail öffnen.
5. Neues Passwort mit mindestens 8 Zeichen setzen.
6. Mit dem neuen Passwort einloggen.

## Hinweis für Produktion

Supabase stellt zum Testen einen Standard-Mailversand bereit. Vor dem öffentlichen Launch sollte unter Authentication → Email / SMTP ein eigener SMTP-Versand eingerichtet und das E-Mail-Template im Origin-Income-Branding gestaltet werden.
