# Origin Income v8.1 — Supabase Auth Foundation

This version adds the technical authentication foundation without changing the visible landing page yet.

## Included

- `@supabase/supabase-js` and `@supabase/ssr`
- Browser Supabase client
- Server Supabase client using Next.js cookies
- Next.js 16 `proxy.ts` for session refresh
- `/api/auth/health` connection check

## Required Vercel variables

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`

Both should be available to Production and Preview deployments.

## Test after deployment

Open:

`https://www.originincome.com/api/auth/health`

Expected response:

```json
{"ok":true,"service":"supabase-auth"}
```

This version does not yet add the login interface. That follows in v8.2.
