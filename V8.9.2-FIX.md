# V8.9.2 – Persistent access fix

## Fixed
- The dashboard reads `profiles` from Supabase on every login.
- A user with `payment_status = paid` and `access_status = active` no longer sees the purchase CTA.
- The active Starter / Pro / Elite plan is displayed in the dashboard.
- Direct visits to `/checkout` redirect paid users back to `/dashboard`.
- Business modules remain marked for V10 because the module content is the next product build.

## Setup
No Stripe, Supabase SQL, or Vercel environment changes are required. Upload the project files to GitHub and wait for Vercel to deploy.
