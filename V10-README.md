# Origin Income V10 — AI Automation Agency Journey

Neu:
- Bezahlte Nutzer können im Dashboard auf „Businessmodell starten“ klicken.
- AI Automation Agency besitzt eine vollständige 7-Phasen-Roadmap.
- Jede Phase enthält Lerninhalte, konkrete Aufgaben, Deliverable und Tool-Stack.
- Aufgaben können abgehakt werden; Fortschritt und Phase bleiben im Browser gespeichert.
- Nächste Phase wird erst nach Abschluss aller Aufgaben freigeschaltet.
- Responsive Premium Journey UI im Origin Income Design.

Hinweis: In V10 speichert die Journey den Lernfortschritt zunächst lokal im Browser. Die Supabase-Synchronisierung des Modulfortschritts folgt als eigener Backend-Schritt, bevor der Live-Launch erfolgt.
