## Vercel Environment Variables

Diese Variablen müssen vorhanden sein:

```env
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_test_...
STRIPE_SECRET_KEY=sk_test_...
```

Optional später:

```env
NEXT_PUBLIC_SITE_URL=https://originincome.com
STRIPE_WEBHOOK_SECRET=whsec_...
```

## Testablauf

1. V8.8 in GitHub hochladen.
2. Vercel Deployment abwarten.
3. Assessment durchführen.
4. Registrieren / Einloggen.
5. Im Dashboard ein Business-Modell auswählen.
6. Button „Zugang freischalten“ klicken.
7. Paket wählen.
8. Stripe Testkarte verwenden:
   - Kartennummer: `4242 4242 4242 4242`
   - Ablaufdatum: beliebig in der Zukunft
   - CVC: beliebig, z. B. `123`
9. Nach erfolgreicher Zahlung sollte die Einrichtungsseite erscheinen.
10. Danach zurück ins Dashboard.
