# Origin Income V8.9 — Payment Provisioning

## One-time setup before testing

1. In Supabase open **SQL Editor** and run the complete file `supabase-v8.9.sql`.
2. In Supabase go to **Settings → API Keys** and copy the **Secret key** (`sb_secret_...`). Never share it or expose it in browser code.
3. In Vercel add:
   - Key: `SUPABASE_SECRET_KEY`
   - Value: the complete `sb_secret_...`
   - Sensitive: ON
   - Environments: Production and Preview
4. Redeploy.

## End-to-end test

1. Log into Origin Income Sandbox.
2. Select a business model and a package.
3. Use Stripe test card `4242 4242 4242 4242`, any future date and any CVC.
4. After checkout, the provisioning page waits for the signed Stripe webhook.
5. Confirm in Stripe Workbench that `checkout.session.completed` returned HTTP 200.
6. Confirm in Supabase:
   - `profiles`: plan, paid/active status, customer/session IDs, purchase date.
   - `payments`: one immutable purchase record.
   - `stripe_events`: one processed event ID.

## Security design

- The success URL does not unlock access.
- Only a valid Stripe-signed webhook can write paid/active status.
- Duplicate webhook deliveries are idempotent.
- The Supabase secret key is server-only.
